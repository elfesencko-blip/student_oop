Характеристика предметной области
1. Общая характеристика
Область: управление качеством обслуживания (QoS) в пакетных сетях.
Объект исследования: узел сети (маршрутизатор/коммутатор), обслуживающий потоки пакетов разных классов трафика.
Предмет исследования: влияние политики обслуживания очередей на показатели QoS при заданной нагрузке и наборе классов трафика.
Современные сети передают неоднородный трафик — голос, видео, данные, — по-разному чувствительный к задержке и потерям. При ограниченной пропускной способности узел вынужден решать конфликт между требованиями классов, и именно политика обслуживания определяет итоговое качество для каждого из них.

2. Ключевые понятия
Пакет — единица данных с идентификатором, классом, размером и моментом поступления.
Класс обслуживания — категория трафика (голос, видео, данные) с приоритетом, весом и требованиями QoS.
Очередь — буфер ожидающих пакетов; при переполнении возможны потери.
Дисциплина очереди — правило извлечения пакетов: FIFO, приоритетная, взвешенная.
Планировщик — механизм выбора следующего пакета; вместе с типом очереди образует политику обслуживания.
Сервер — канал с заданной скоростью, определяющий время обслуживания.
Показатели QoS — средняя и квантильная задержка, джиттер, доля потерь, справедливость (индекс Джайни).

3. Классификация политик обслуживания
FIFO — единая очередь, порядок поступления; проста, но не различает классы.
Приоритетная (PQ) — строгое обслуживание высшего приоритета; минимизирует задержку приоритетных, но возможен голод низкоприоритетных.
Взвешенная справедливая (WFQ/DRR) — обслуживание пропорционально весам; компромисс между приоритизацией и справедливостью.
Циклическая (RR) — поочерёдное обслуживание очередей классов.
Сравнение этих политик по показателям QoS при варьировании нагрузки и параметров составляет содержание исследования.

4. Суть проблемы
При низкой нагрузке различия политик незначительны; при приближении нагрузки к пропускной способности проявляются компромиссы: приоритетная политика удерживает задержку высшего класса ценой потерь низшего, FIFO распределяет страдание равномерно, WFQ сохраняет пропорции. Задача — количественно оценить эти компромиссы и определить условия предпочтительности каждой политики.
